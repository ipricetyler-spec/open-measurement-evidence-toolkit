# Support

Use GitHub issues for reproducible defects and narrowly scoped feature requests after the repository is public. Include the toolkit version, operating system, .NET version, minimal synthetic input, expected result, and actual result.

Do not upload personal telemetry, hardware identifiers, account data, proprietary game assets, or evidence you lack permission to share. Use the private security channel described in [SECURITY.md](SECURITY.md) for vulnerabilities.
