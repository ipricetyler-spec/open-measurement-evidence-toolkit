# Roadmap

## 0.1 release gate

- Complete namespace and terminology separation from the private product.
- Pass all synthetic tests from a clean checkout on Windows.
- Verify the public-source boundary and third-party notices.
- License selected and added: Apache License 2.0.
- Publish schemas with stable identifiers and examples.
- Create the public repository and enable branch protection, private vulnerability reporting, and dependency alerts.

## After 0.1

- Add a small command-line validator without expanding into capture or system mutation.
- Collect real user feedback through issues while keeping fixtures synthetic.
- Add cross-platform parsing where Windows held-file guarantees are not required.
- Define a compatibility policy and tagged release cadence from demonstrated demand.

## Program readiness

Codex for Open Source readiness requires an active public repository, meaningful usage or clear ecosystem importance, and evidence of real maintenance. Documentation and automation can prepare the project, but they cannot substitute for genuine users, issue triage, releases, or ecosystem value.
