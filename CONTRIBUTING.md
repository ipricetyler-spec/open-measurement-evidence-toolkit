# Contributing

Thank you for helping improve reproducible performance evidence.

Before proposing code, open a focused issue describing the observed problem, a minimal synthetic reproduction, and the expected behavior. Pull requests should remain inside the offline evidence boundary, include deterministic tests, and avoid real user telemetry or copyrighted capture data.

Run the local maintenance check before submitting:

```powershell
./scripts/maintain.ps1
```

Contributions that add capture control, system mutation, privilege elevation, game injection, anti-cheat interaction, tracking, or network services are outside the project scope.

By submitting a contribution, you represent that you have the right to submit it under the repository's selected license:

- Apache-2.0 (the repository license).
